# Acknowledgements and project lineage

This repository descends from two open-source projects:

1. [Claude Status Bar](https://github.com/m1ckc3s/claude-status-bar), created by **Mick Cesanek**, established the native macOS menu-bar architecture, interaction model, completion sound, and Claude visual language. Mick's MIT copyright notice remains in [LICENSE](LICENSE).
2. [Lasse's Codex Status Bar](https://github.com/lassejlv/codex-status-bar), created by **Lasse**, adapted that project for Codex and introduced Codex lifecycle handling and the pet-oriented interface that this repository originally forked.

Nick Mauro's edition removes the pet and CLI-hook systems and rebuilds the product around Codex Desktop's local lifecycle stream, exact active-task titles, completion alerts, login-item behavior, and universal GitHub releases.

Thank you to Mick, Lasse, and every contributor whose work remains in the repository history.

The Claude spark icon and completion sound are carried forward from the original project.
